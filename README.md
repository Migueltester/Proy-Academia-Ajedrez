# Proy-Academia-Ajedrez
Proyecto de una academia de ajedrez de la carrera de ingenieria de software


Modelado del Sistema 

DOCUMENTO VISIÓN 

Introducción Propósito 

El propósito de esta visión es proponer una solución de software que aborde los problemas de desorganización en la academia de ajedrez. El software buscará llevar un registro eficiente de todos los estudiantes inscritos con sus respectivos horarios de clase, los profesores y sus horarios, así también como facilitar el proceso de inscripción y organización de los torneos, garantizando que los emparejamientos sean justos, esto tomando en cuenta el ranking de los jugadores. 

Alcance 

Este documento contiene la información detallada sobre la solución de software propuesta para la academia de ajedrez, abarcando aspectos como la gestión de estudiantes inscritos, horarios de clases, registro y asignación de profesores, así como el proceso de inscripción y organización de torneos. Además, incluirá un sistema de emparejamiento de jugadores basado en su ranking. 

Definiciones, acrónimos y abreviaciones 

Cuaderno de registro: Registro físico en donde se anotan los datos de los estudiantes, horarios de clases, materiales solicitados por profesores, entre otros detalles que sean de importancia para la academia.
